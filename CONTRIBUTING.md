# Contributing to This Project

Thank you for your interest in contributing! This project is part of the OpenRoot ecosystem.

## How to Contribute

### 1. Fork and Clone
```bash
gh repo fork jesseray718/[repo-name] --clone
```

### 2. Create a Branch
```bash
git checkout -b feature/your-feature-name
```

### 3. Make Your Changes
- Follow existing code style
- Add tests if applicable
- Update documentation as needed

### 4. Test Your Changes
- Ensure all existing tests pass
- Test on your hardware/setup if applicable

### 5. Submit a Pull Request
```bash
gh pr create --title "Description of changes" --body "Fixes #issue-number"
```

## Code of Conduct

- Be respectful and inclusive
- Focus on constructive feedback
- Help others learn

## Questions?

- Open an issue: https://github.com/jesseray718/[repo-name]/issues
- Start a discussion: https://github.com/jesseray718/[repo-name]/discussions
